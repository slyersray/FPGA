加密模块需求
● 目标平台：Agliex-7, AGI x027.022 FPGA，工作频率 400 MHz，总线宽度 1024 bit。
● 性能指标：支持 400Gbps 吞吐量。
● 算法要求：支持 AES256 与 SM4 算法，客户可提供 C 语言比特级参考模型。
● 资源限制：该模块占用 IP 资源不超过 25%～30%。

压缩模块需求
● 数据类型：16 bit BF16 浮点数构成的多维 Tensor 数据。
● 处理方式：包含简单无损压缩（如哈夫曼编码）和基于矩阵运算的压缩变换及量化（量化至 4 bit）。
● 性能指标：输入数据速率 400Gbps，压缩后速率降低至 1/2 或 1/4。
● 资源限制：该模块占用 IP 资源不超过 25%～30%，整体逻辑资源占用控制在 50%～60% 以内。
